¿Qué hace la extensión azure_ai?

Agrega funciones SQL que llaman a los servicios de Microsoft Foundry desde el propio servidor de PostgreSQL.

azure_openai
Embeddings con un modelo de Foundry: create_embeddings()
azure_cognitive
Azure AI Language: sentimiento, idioma, frases clave, entidades, PII, resúmenes
azure_ai (preview)
Operadores semánticos con LLM: generate(), is_true(), extract()
