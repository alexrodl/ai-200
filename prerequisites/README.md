# Prerequisites

## Perfil recomendado

El curso es de nivel intermedio y está dirigido a desarrolladores backend y de aplicaciones con IA en Azure. Microsoft recomienda experiencia de programación (especialmente Python en los módulos de datos y backend), conocimientos básicos de Azure y cloud computing.

Antes del curso, conviene tener:

- Fundamentos de HTTP, APIs, autenticación y línea de comandos.
- Experiencia con Python; JavaScript o C# pueden ser útiles para el trabajo con aplicaciones.
- Fundamentos de contenedores; familiaridad con Kubernetes para el módulo de AKS.
- SQL y JSON; conceptos de embeddings y búsqueda vectorial para los módulos de datos.
- Comprensión de colas, eventos y procesamiento asíncrono para backend distribuido.

## Preparación del entorno

### Azure subscription

Se necesita acceso a una suscripción de laboratorio autorizada, con cuota/región disponibles para los servicios que se vayan a utilizar. La creación y el acceso a cada recurso dependen de los ejercicios del módulo. Consulta [Azure setup](azure.md) y [Accounts and permissions](accounts.md).

### Herramientas recomendadas

- Azure CLI
- `kubectl` para el módulo de AKS
- Git
- Visual Studio Code
- Python y los SDK indicados por los ejercicios
- Docker es opcional para las prácticas que usan ACR Tasks; sigue el requerimiento concreto del ejercicio

## Recursos recomendados

- [Azure fundamentals](https://learn.microsoft.com/training/paths/azure-fundamentals-describe-azure-architecture-services/)
- [Install Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
- [Install kubectl](https://learn.microsoft.com/azure/aks/learn/quick-kubernetes-deploy-cli)
- [Python downloads](https://www.python.org/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/)

## Antes de cada laboratorio

- Lee la guía local del laboratorio y confirma las cuotas, permisos, herramientas y región requeridos.
- Usa solo la suscripción autorizada para el curso, nunca un entorno de producción.
- Reserva tiempo para eliminar los recursos al terminar.
